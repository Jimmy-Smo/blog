# 精选周刊

周刊负责提供时间线和阅读入口，不承担知识正文。专题文章保存完整结论、原理和实践，周刊只做筛选、串联和简短判断。

## 发布原则

- 不强制周更；没有足够内容时直接跳过，也可以改成月度合集。
- 每期尽量在 30 分钟内完成，避免为了日期制造内容。
- 优先链接本仓库的专题文章，不复制大段正文。
- 外部资料说明推荐理由，并保留原始来源。
- 工作细节、个人复盘和未核验信息仍留在私有 `learning-vault`。

新一期从 [`_template.md`](_template.md) 开始。建议文件名使用 `YYYY-Www.md`，例如 `2026-W29.md`。
