## 📚 学习要点（主题拆分）

### 1) 版本发布与 Git 实操
- **发布基线**  
  - **release 分支**完成：版本号提升、`CHANGELOG.md` 更新。  
  - 合并至 **main** 后再 `git tag vX.Y.Z && git push --tags`，随后生成 Release Notes。  
- **VS Code 将 release 合并到 dev**  
  1. 切换 `dev` → 2) “Merge Branch…” 选择 `release/*` → 3) 解决冲突、提交 → 4) `git push origin dev`。  
- **是否在 release 打 tag？**  
  - 统一在 **main** 上打稳定版本 tag，便于回溯与 CI 产物对齐。  
- 建议补充 `RELEASING.md`（流程、校验清单、回滚策略）。

### 2) AI 编程工具对比与选型（Claude Code / Cursor / Copilot / ChatGPT）
- **关注维度**：IDE/Terminal 集成、团队协作（Code Review/子代理）、隐私与日志留存、速度与推理质量、成本（$20–100/人·月）。  
- **组合建议（Java/Kotlin & Spring Boot）**  
  - **Cursor**：本地上下文/语义搜索+多轮改写；  
  - **Claude Code**：长上下文/子代理（代码审查、文档重写）；  
  - **Copilot**：行内补全与测试样例骨架；  
  - **ChatGPT**：架构讨论、脚本/SQL/正则一次性生成与核对。

### 3) 网络诊断与 DNS/代理
- **工具速查**  
  - `ping`（连通性/抖动）、`traceroute`（路径、星号=中间节点无回包/被丢弃）、`nc`/`telnet`（TCP 端口可达性）、`curl`（HTTP 细节）、`nmap`（端口/服务识别）、`dig`（DNS 解析链路）、`ss -tlnp`（Linux 监听）。  
  - `telnet` 逃逸：**`^]`**（Ctrl + ]）进入命令模式。  
- **dig 识别使用的 DNS**：对比 `+trace` 递归过程与系统 `resolv.conf` / 网络偏好设置；路由器侧可直设公共 DNS（如 114.114.114.114/DoH），但需评估运营商劫持与分流策略。  
- **`traceroute` 出现 `192.18.0.1` 等非私网地址**：识别为保留/测试网段或运营商内部路由节点；星号并不必然代表丢包。

### 4) Surge × AdGuard 冲突与排查
- **结论**：Surge **增强模式（TUN）** 与 AdGuard **系统过滤/DNS 保护/PAC** 同开会抢占系统代理与路由 → 产生不可预期出站行为。  
- **修复动作**  
  - 关闭 AdGuard：① 自动过滤应用流量② 自动代理/PAC③ DNS 保护（或直接退出/卸载）。  
  - Surge 仅开 **增强模式**，一般无需再设系统代理。  
  - 使用 bash 脚本核对当前路由表/系统代理与 TUN 状态，验证变更已生效。

### 5) Docker（macOS 26）安装与资源治理
- **安装校验**：`docker run hello-world`；删除容器用 `docker rm <CONTAINER_ID/NAME>`（需容器已退出）。  
- **资源限额**：给 Docker 预留 **4 GiB** 足以支撑入门实验；可关闭开机自启以减小常驻内存压力（16 GiB 机器尤需）。  
- **镜像加速**：可切换阿里云/清华/腾讯镜像站（谨慎配置、留意条款与证书）；  
- **学习路径**：镜像层/UnionFS → `Dockerfile` 基础 → `compose` 服务编排 → 本地开发热加载。

### 6) Python 3.14 与 Shell 环境
- **并存策略**：macOS 自带 `python3.9` + Homebrew `python@3.14` 共存，PATH 前后顺序决定默认版本；不想覆盖系统 Python，可仅在 venv 内指定。  
- **虚拟环境**：项目目录下重建 `.venv` 指向 3.14；`python3.14 -m venv .venv && source .venv/bin/activate`。  
- **卸载旧版**：`brew uninstall python@3.13`；保留 Docker CLI 补全的 `.zshrc` 片段（便于 `docker` 补全），非刚需可暂注释以简化启动。

### 7) macOS 安全与系统工具
- **iTerm2「安全键盘输入」**：防止其他进程截获按键（输入密码场景开启）。  
- **FileVault**：全盘加密；台式机固定场景可选开/关，移动设备与涉敏数据强烈建议开启；拆盘在其他设备无法读取（无密钥/凭证）。  
- **端口占用排查**：`lsof -iTCP:8080 -sTCP:LISTEN -n -P` → `kill -15` 优先，必要时切 `--server.port`。

### 8) 数据库与中间件
- **MyBatis-Plus `OptimizeCountSql`**：分页 `COUNT(*)` 自动裁剪无关 `SELECT` 字段/`LEFT JOIN`，降低计数开销（语义：仅为总数估算，极端场景与特定方言需验证）。  
- **RabbitMQ 连接故障排查**：校验 `host/port/vhost/凭据/TLS/安全组`，结合 `prefetch`、并发与重试策略；优先以 **外部化配置（Nacos / application*.yml）** 覆盖代码默认。  
- **集合类型选择**：`LinkedHashSet` 既去重又保序，适合“去重但保留遍历顺序”的结果集。

### 9) 其他碎片知识
- **nmap/ss 安装**：`nmap` 跨平台，macOS 可 `brew install nmap`；`ss` 属 Linux（`iproute2`），在 macOS 用 `lsof/netstat` 替代。  
- **iPhone 16e vs 16**：识别“频点/内存/屏幕/相机/材质”等差异维度，结合预算与需求做取舍。  
- **IRS 4506-C / Transcript**：理解征信/核件链路可能导致审批周期拉长的现实；电话沟通建议先问原因与预计时效，再按需补件/转接 supervisor。
